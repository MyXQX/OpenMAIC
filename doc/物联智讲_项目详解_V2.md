## 1. 一句话定位与架构定位

在第一版（V1）MVP 中，物联智讲主要作为一个并行的独立模块挂载在 OpenMAIC 项目的 `/wulian` 目录下，仅实现了极简的多 Agent 状态机与 RAG 检索，且并未复用 MAIC 的课件播放内核与生成流水线。

**V2 版本的核心定位是：将 Wulian 升级为复用 OpenMAIC 内核的完整大学物理教学交互产品。**

Wulian V2 遵循以下设计哲学：
- **深度内核复用，界面独立定制**：完全复用 MAIC 的大纲评估、媒体生成、PlayBack 回放引擎、Action 动作引擎、Zustand 全局状态 store 及 SVG 白板系统，而播放器界面则重新定制，剥离无关的幻灯片缩略图区，专为多 Agent 实时对话、物理实验台操作与公式推导板书而设计。
- **账号隔离与访客阻断**：引入了严格的基于 Session / Cookie 的多账号安全隔离机制。对于未登录的访客，前端通过在多处定制向导、个人资料页及上传区域实施交互阻断，引导用户登录，确保存储安全与隐私。
- **即时 TTS 音频生成与缓存**：Wulian 课堂生成时关闭了预生成音频（`enableTTS: false`），并在播放时提供 TTS 语音开关。一旦开启，利用客户端包裹层拦截播放请求，通过 Edge-TTS 服务端按需即时（on-the-fly）合成，并持久化缓存至 IndexedDB 中。

## 2. V2 版本重大升级成果

### 2.1 基于 MAIC Orchestration 的对话编排
废弃了 V1 版本中自建的极简有限状态机（`orchestrator.ts`），全面改用 OpenMAIC 的 `lib/orchestration`（基于 LangGraph 编排的导演图模型）。通过 `mapWulianAgentsToMaic`，动态将 Wulian 的科学家 Persona（如法拉第、麦克斯韦、爱因斯坦等）、助教小麦与同学小恒映射为标准 MAIC AgentConfig。

### 2.2 多账号命名空间隔离与安全保障
- **服务端用户隔离**：所有的课堂定制实例、个人画像、上传的原文档和对应的向量数据全部隔离在 `data/wulian/users/<userId>/` 目录下。
- **403 越权防护**：接口在读取定制课堂实例或修改画像时，会检验 instance 所有人与 Session 中当前登录的 `userId` 是否一致，非法越权请求将一律返回 `403 Forbidden`。

### 2.3 访客模式前端阻断与会话迁移
- **前端阻断**：访客模式下禁止使用「我的资料」和「对照」定制模式，禁止上传外部文档，并友好提示引导用户登录。
- **会话持久化与迁移**：访客定制的生成课堂数据暂存在客户端 IndexedDB/Dexie 中，用户登录后，可通过 `migrateLocalDataToAccount` 一键将本地生成的实例和资料同步迁移至服务端个人目录下。

### 2.4 多 Agent 互动播放器外壳
构建了全新的三栏播放器 [ClassroomPlayer.tsx](file:///c:/Users/xqx/Documents/code_libraries/digitalAI/openmaic-plan/app/wulian/components/ClassroomPlayer.tsx)，它集成了：
- **时序进度条 (VideoProgressBar)**：根据各 Scene 中 Agent 发言的动作时长估算总时长，支持多倍速切换（0.5x ~ 2.0x）与进度拖动。
- **字幕层 (SubtitleOverlay)**：订阅回放引擎，实时渲染科学家、助教或学生的流式文本发言字幕。
- **白板覆盖层 (MaicWhiteboard)**：在 16:9 PPT 课件画面正上方动态叠加 MAIC SVG 白板，将播放时的动作引擎板书、公式推导画笔实时投射在 PPT 幻灯片上。
- **即时 TTS 音频缓存**：包装 `audioPlayer.play`，自动调用 `/api/generate/tts` 并存储到本地 IndexedDB 的 `db.audioFiles`，实现离线再次播放免流量。
- **模拟器状态实时控制**：在 interactive 场景下，动作引擎的 `widget_setState` 动作通过 `ActionEngine` 派发消息给客户端，实时修改模拟器控制变量，渲染动态交互物理实验。

## 4. 数据模型与存储结构

### 4.1 目录结构与隔离约定
为确保存储安全，所有运行时写入数据统一按照 `userId` 在 `data/wulian/users/` 下隔离存储：
- `data/wulian/users/<userId>/profile.json`：存放学生的画像偏好（基础底子、年级、目标等）与配置。
- `data/wulian/users/<userId>/classrooms/<classroomId>.json`：该用户在该章节定制生成的课堂实例（含 stage 结构与 scenes 列表）。
- `data/wulian/users/<userId>/uploads/<docId>.<ext>`：该用户上传的私有文档源文件（PDF/TXT/MD）。
- `data/wulian/users/<userId>/vectors/<docId>.json`：该文档提取切分后的 chunk 及语义向量数据。
- `data/wulian/feedback/<yyyymmdd>.jsonl`：全局收集的随堂练习做题情况与课后评分日志。

### 4.2 客户端 IndexedDB Caching (Dexie)
在客户端浏览器中，复用了 MAIC 原生的 IndexedDB 数据库 `MAIC-Database`：
- `db.audioFiles`：在 TTS 实时合成时，用来永久缓存音频流：
  ```ts
  interface AudioFileRecord {
    id: string;        // 复合键: "wulian_tts_<sceneId>_<actionId>"
    blob: Blob;        // 音频二进制
    format: string;    // "mp3"
    text: string;      // 对应的文字
    voice: string;     // 使用的声音标识
    createdAt: number; // 写入时间戳
  }
  ```

## 5. 前端 UI 布局与页面流转

物联智讲 V2 版本采用**「网关拦截 → 定制表单 → 轮询生成 → 核心播放器」**的流转链路：

```
                                  点击章节卡片
                                       │
                                       ▼
                             ┌───────────────────┐
                             │    InitGate.tsx   │ ◀─────── 检查是否已有该章节定制实例
                             └─────────┬─────────┘
                                       │
                       ┌───────────────┴───────────────┐
                     无实例                             有实例
                       │                               │
                       ▼                               ▼
             ┌───────────────────┐           ┌───────────────────┐
             │  SetupWizard.tsx  │           │ClassroomPlayer.tsx│
             └─────────┬─────────┘           └───────────────────┘
                       │
         ┌─────────────┴─────────────┐
         ▼                           ▼
  [ 确认并提交生成 ]          [ 轮询 Job 进度 ]
         │                           │
         ▼                           ▼
  POST /api/wulian/classroom  GET /api/wulian/classroom/[jobId]
         │                           │
         └─────────────┬─────────────┘
                       │ 生成 100% 完成
                       ▼
             跳转 ClassroomPlayer 播放
```

### 5.1 生成网关判定 (InitGate.tsx)
当用户访问 `/wulian/lesson/[id]` 时，首先渲染 `InitGate`。它在本地/服务端检索该用户在此章节中是否已经生成过课堂。如果已存在，则直接拉起 `ClassroomPlayer`；如果不存在，则渲染四步个性化定制表单。

### 5.2 步骤式定制向导 (SetupWizard.tsx)
- **第一步：学生画像**（选择水平：入门/进阶/高级；选择节奏：慢速/中速/快速）。
- **第二步：资料来源**（课程内置/我的资料/对照学习；访客状态下「我的/对照」会被阻断，并提示登录）。
- **第三步：物理模拟器嵌入**（在 4 个实验台中勾选希望加入本课讲解的模拟器）。
- **第四步：确认生成**（点击后发起 POST 异步 Job，展示环形与分步进度，100% 后流转至播放器）。

## 6. 多智能体课堂对话编排（Orchestration）

Wulian V2 摒弃了简易的串行生成，完全基于标准 OpenMAIC 的 LangGraph 导演编排系统完成课堂实时答疑。

```
                    POST /api/wulian/chat (学生提问)
                                │
                                ▼
         调用 mapWulianAgentsToMaic(primary, secondary)
                                │
       将 Primary(Teacher), Secondary, Xiaomai, Xiaoheng Mapped
                                │
                                ▼
                构造并调用 lib/orchestration 导演图
                                │
                 SSE 事件流返回 (WulianStreamEvent)
```

1. **角色映射 (mapWulianAgentsToMaic)**：
   - 将主讲科学家映射为 MAIC Agent 中的 `teacher`，注入特定的系统提示词 Persona、研究领域和配音风格（`voiceStyle`）。
   - 将副讲科学家（如有）映射为 `secondary_teacher`。
   - 助教小麦（`assistant`）与同学小恒（`classmate`）映射为协讲与学生提问助推角色。
2. **对话流返回规约**：
   - 对话请求通过 SSE（Server-Sent Events）向前端推送。
   - 流式解析 LLM 的输出。在输出 JSON 的过程中，客户端能从 `"speech"` 字段中截取流式 delta token 输出到字幕中，等整个事件完全结束，再提取并执行其 `whiteboard` 板书公式或 `quiz` 随堂卡片。

## 7. 核心业务生命周期与数据流

### 7.1 定制生成生命周期
1. 用户在 `SetupWizard` 勾选配置，发送画像、资料模式、模拟器 ID 及专属提示词至 `POST /api/wulian/classroom`。
2. 后端读取学生画像偏好，调用 `buildGenerationRequirements`。
3. `buildGenerationRequirements` 进行 RAG 文档召回，将检索片段组织为大纲上下文注入。同时，将勾选的物理模拟器 ID 转译为场景评估器的大纲互动约束（constraints）。
4. 启动异步 Job 跑 OpenMAIC 的 `generateClassroom` 管道：
   - **Phase 1: 大纲生成与微调**（`generating_outline`）
   - **Phase 2: 填充课件幻灯片内容**（`generating_scenes`）
   - **Phase 3: 绑定媒体占位与交互注入**（`generating_media`，在此阶段，Wulian 仅绑定模拟器适配器 URL，同时指定 `enableTTS: false` 以获得秒级生成速度）。
5. 最终生成 `WulianClassroomInstance` 实例。如果用户已登录，写入 `data/wulian/users/<userId>/classrooms`；若为访客，直接塞进 job result payload 中返回，由前端落入本地 IndexDB。

### 7.2 播放回放与 TTS 懒加载生命周期
1. 启动 `ClassroomPlayer`时，在 `useEffect` 中，将 instance 内的 `scenes` 与 `stage` 数据注入 OpenMAIC 的 `useStageStore` 中，并对所有 speech action 写入稳定的唯一标识 `audioId` (如 `wulian_tts_sceneId_actionId`)。
2. 实例化回放引擎 `PlaybackEngine` 与包裹的 `AudioPlayer`。
3. 当科学家开始在幻灯片中讲解时，`PlaybackEngine` 读取 speech 动作，调用 `audioPlayer.play(audioId)`。
4. **包裹的 `AudioPlayer.play` 拦截**：
   - 检查 `db.audioFiles.get(audioId)`。
   - 若命缓存，直接转换 Blob URL 并调用原生音频播放。
   - 若未命缓存，通过 Fetch 将文本、声音标识与当前选用的 TTS 厂商密钥发送至 `/api/generate/tts`。
   - 服务端即时合成 base64 字节流并返回，客户端解码为二进制 Blob，通过 `db.audioFiles.put` 存入 IndexedDB 离线区，最后调用 `originalPlay()` 正常播放。
5. **只读模拟器控制**：当遇到 `widget_setState` 动作（如科学家调整实验参数）时，`ActionEngine` 的 callback 捕获事件，修改播放器的 `controlledParams` 状态。此时，在播放主视口渲染的 `SimulatorSceneRenderer` 接受到外部受控参数变化，使物理模拟器自动更新。

## 8. 系统异常处理与安全保障

### 8.1 Windows 原子写文件锁冲突避让 (Windows EPERM Lock)
在 Windows 环境下进行并发原子写（Temp file -> rename）时，由于文件句柄释放的延迟，容易抛出 `EPERM` 权限占用异常。Wulian 在 `writeUserJsonAtomic` 底层实现中封装了退避重试（backoff/retry）算法：
- 当捕获 `EPERM` 错误时，进行最多 5 次指数退避延时重试（每轮等待 10ms ~ 80ms 随机微秒），直到文件锁释放，确保了 Windows 单机并发场景下的写入稳定性。

### 8.2 越权读取拦截 (OwnershipError)
在 `/api/wulian/classroom/instance/[id]` 和 `/api/wulian/profile` 中实施了严格的归属权校验：
- 当试图读取实例时，后端会比对 `instance.owner` 是否与 Session `userId` 一致。如果不符，抛出 `OwnershipError` 并返回 `403`，彻底阻断同一局域网下或不同浏览器标签的越权窃听。

### 8.3 客户端 SSRF URL 过滤安全防范
在 `/api/generate/tts` 服务端即时合成接口中，支持客户端临时指定第三方 TTS endpoint 地址（`ttsBaseUrl`）。为防范服务器端请求伪造（SSRF）向局域网内部服务渗透，该参数在进入生成前，会通过 `validateUrlForSSRF` 安全网关进行黑名单 IP（包括 `127.0.0.1`、`192.168.*` 及内网 DNS 地址）强过滤。

## 9. API 接口详解

### 9.1 `POST /api/wulian/classroom`
创建物理课堂定制生成异步任务。
- **请求体**：
  ```ts
  interface WulianPersonalizationInput {
    chapterId: string;
    studentProfile: StudentProfile;
    materialMode: 'course' | 'mine' | 'compare';
    uploadedDocIds: string[];
    selectedSimulatorIds: string[];
    extraInstructions?: string;
  }
  ```
- **返回**：`{ success: true, jobId: "job-xxx" }`

### 9.2 `GET /api/wulian/classroom/[jobId]`
轮询任务的生成状态与当前进度。
- **返回**：
  ```ts
  {
    success: true,
    job: {
      id: string,
      status: 'queued' | 'running' | 'completed' | 'failed',
      step: 'generating_outline' | 'generating_scenes' | 'generating_media' | 'completed',
      progress: number, // 0 ~ 100
      classroomId?: string, // 成功后返回实例 ID
      error?: string
    }
  }
  ```

### 9.3 `GET /api/wulian/classroom/instance/[id]`
拉取定制课堂的完整 scenes 和 stage 细节。
- **Header 限制**：会校验 Cookie 中的 Session 并与 `owner` 对比。
- **返回**：`{ success: true, instance: WulianClassroomInstance }`，非本人抛 `403`。

### 9.4 `GET/PUT /api/wulian/profile`
读写个人画像配置。
- **返回**：`{ success: true, profile: StudentProfile }`

### 9.5 `POST /api/wulian/chat`
多 Agent SSE 流式对话接口。
- **请求体**：与标准 MAIC `/api/chat` 兼容，返回 `WulianStreamEvent`。

### 9.6 `POST /api/generate/tts`
单句 TTS 即时音频合成。
- **请求体**：
  ```ts
  {
    text: string,
    audioId: string,
    ttsProviderId: string, // 如 "azure-tts" / "voxcpm-tts"
    ttsVoice: string,
    ttsSpeed?: number
  }
  ```
- **返回**：`{ success: true, audioId: string, base64: string, format: "mp3" }`
